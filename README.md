# 京华自然志

面向北京市大学生数字媒体设计竞赛的可运行网页作品。以北京的花木、湿地、鸟类、古树与山地为线索，把十个自然主题做成一份可以阅读、也可以行走的「自然志」：每个主题都有从线稿到成图的推演、观赏月份、观赏地点，以及文化脉络与城市变迁两条延伸线。

站点为纯静态页面，无框架、无构建步骤、无外部依赖，全部使用原生 HTML / CSS / JavaScript。

## 本地预览

方式一（推荐）：项目根目录下运行自带静态服务器，然后访问 <http://127.0.0.1:4173>。

```powershell
node preview-server.mjs
```

> `preview-server.mjs` 是开发用的小型静态服务器，已在 `.gitignore` 中忽略、不随仓库发布。克隆仓库后可用任意静态服务器替代，例如 `npx serve` 或编辑器的 Live Server 插件。

方式二：直接双击 `index.html`。北京行政区底图数据已内联在 `scripts/beijing-districts.js` 中，不依赖网络请求，因此 `file://` 下地图同样可用。

## 内容规模

- **10 个自然主题**，分入 5 个分组：花木 3、湿地 2、鸟类 2、古树 1、山地 2
- **26 个观赏地点**，覆盖 11 个行政区，底图为北京 16 区行政边界
- 每个主题 **4 个分节**（花期与形态 / 栽植环境 / 城市分布 / 物种特征，各主题按内容调整）
- 每个主题都有「自然文脉」与「发展之路」两条延伸线
- 素材 **139 张**，按主题分目录；`material/shouye/` 中十个主题各有一套「线稿 → 过渡 → 完整版」三阶段图（首页轮播与分类页使用），各主题目录另有三阶段图供主题页使用（早春玉兰与林下二月兰的成图以 `-color` 命名）

## 主要交互

**首页**

- 线稿→上色轮播，逐帧揭示十个主题
- 「自然年历」按月份筛选主题，轮播同步跳到当月第一个主题
- **打开即落在当月**：当月主题带「本月」角标，月份按钮有实心下划线；点「今天」印章可随时回到本月。本次会话内手动选过的月份会被记住，从主题页返回首页不会丢失
- 「播放展览」自动巡展十个主题（状态只存在本标签页，用户任何一次操作都会立刻取消跳转，不会把人从当前页带走）

**主题页**

- 拖动进度条（或自动播放）看线稿逐步上色为成图
- 点击画面展开当前分节的文字说明

**观赏地图**

- 类别 × 月份 × 主题三重筛选，选中地点显示详情；筛选与选中状态写入地址栏，可直接分享
- 标记悬浮卡显示地点名、主题、所在区与最佳观赏时间
- 选中地点会拉一条虚线引线到所属行政区中心，并高亮该区
- 拖拽平移 + `Ctrl`/`⌘` + 滚轮缩放（也可用 `+` / `−` / `复位` 按钮）；缩放时标记反向缩放，始终保持自然大小
- 半日路线：最多 4 站，用虚线连接并估算总时长，超过 4.5 小时自动改称「全日路线」

**自然文脉 / 发展之路**

- 右侧章节滑轨显示阅读进度，滚动时自动高亮当前章节
- 十个主题用纯链接标签切换，每个主题都有独立地址，可直接分享

**全站**

- 深链参数：`?theme=`（主题）、`?month=`（月份）、`?place=`（地点）、`?panel=`（分节）、`?from=`（返回目标）
- 尊重 `prefers-reduced-motion`，关闭动画偏好时不播放浮动与花瓣动效

## 数据源

| 文件 | 内容 |
| --- | --- |
| `scripts/theme-calendar.js` | 十个主题、观赏月份、封面图、展览模式状态机；首页年历与观赏地图共用 |
| `scripts/guide.js` | 十组主题信息（时间、时长、观察重点、观赏建议）与 26 个观赏地点（坐标、区、位置、说明） |
| `scripts/culture-data.js` | 十个主题的诗咏、文化线索、延伸阅读与资料来源 |
| `scripts/history-data.js` | 十个主题的时间线、关键数据与资料来源 |
| `scripts/beijing-districts.js` | 北京行政区边界，内联以避免 `file://` 下取不到底图 |

## 参赛录屏建议

建议使用 1920×1080 分辨率，按以下顺序演示：

1. 首屏：首页标题与作品概念，线稿→上色轮播
2. 自然年历：切换月份，看主题筛选与轮播联动（说明默认落在当月）
3. 分类页：五个分组的主题卡片与分节入口
4. 主题页：拖动进度条看线稿逐步上色，点开分节文字
5. 观赏地图：类别与月份筛选 → 选中地点看引线 → 缩放平移 → 加入两站生成半日路线
6. 自然文脉与发展之路：诗咏、时间线与阅读滑轨
7. 「播放展览」自动巡展收尾
