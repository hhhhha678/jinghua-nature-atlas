# 京华自然梦境图鉴

一个面向北京市大学生数字媒体设计大赛的可运行网页作品概念，围绕北京的花、草、动物、树与自然景观，提供图鉴信息和梦境观察两种浏览方式。

## 本地运行

在项目目录执行：

```powershell
node preview-server.mjs
```

然后打开：

```text
http://127.0.0.1:4173
```

也可以直接双击 `index.html` 查看静态页面。

## 在线预览

项目通过 GitHub Pages 发布静态网页，仓库根目录中的 `index.html` 为访问入口。

## 页面内容

- 5 个自然章节
- 10 个代表对象
- 图鉴信息 / 梦境观察模式切换
- 章节筛选、对象卡片、随机切换
- Canvas 粒子背景和 SVG 自制主视觉
- 桌面端、笔记本端和移动端响应式适配

## 参赛录屏建议

录屏时建议使用 1920×1080 分辨率，按以下顺序演示：

1. 首屏标题和作品概念
2. 五个自然章节入口
3. 花、动物、景观三个代表章节
4. 图鉴信息与梦境观察切换
5. 点击对象卡片、随机按钮和微动效
6. 创新想法区域
